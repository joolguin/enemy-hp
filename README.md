# Enemy HP Multipliers

Multiplica la vida de los enemigos, con un ajuste para cada categoría: enemigos normales, minijefes,
jefes de mazmorra y jefes finales (1x, 1.5x, 2x, 2.5x, 3x, 4x, 5x, 8x). Las listas de jefes vienen de
A Link Between Twilight (CC0).

- El daño que recibe Link se ajusta en Dusklight: Settings → Difficulty → Damage Multiplier.
- El cambio aplica a los enemigos que aparecen después de cambiar la opción.
- Algunos jefes vuelven a fijar su vida entre fases; en esos casos no todas las fases cambian.

## Compilar
Igual que Hero's Tunic Wardrobe: subir a un repo de GitHub y GitHub Actions compila `mod-macos-arm64`.
Este repo puede ser público: no trae archivos del juego ni de otros autores.
